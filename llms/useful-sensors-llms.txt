# Useful Sensors (Moonshine AI)

> Useful Sensors, now operating as Moonshine AI, builds fast, low-resource, private-by-design AI that runs entirely on-device: the Moonshine family of low-latency speech-to-text, text-to-speech, and intent-recognition models with SDKs for in-browser JavaScript, server-side Python, and C++ on edge devices, plus earlier plug-and-play hardware (Person Sensor, Tiny Code Reader). Founded by former Google TensorFlow leads Pete Warden and Manjunath Kudlur. There is no hosted cloud API — all processing happens locally.

Generated by the API Evangelist enrichment pipeline (2026-07-21) from apis.yml and repo artifacts; the provider publishes no /llms.txt of its own.

## SDKs and Packages

- [moonshine-voice on PyPI](https://pypi.org/project/moonshine-voice/): current Python SDK; also installs the moonshine-voice / moonshine CLI (mic, transcribe, tts, intent, download, g2p)
- [@moonshine-ai/moonshine-js on npm](https://www.npmjs.com/package/@moonshine-ai/moonshine-js): in-browser speech-to-text and voice control
- [moonshine-swift](https://github.com/moonshine-ai/moonshine-swift): Swift Package Manager distribution for iOS/macOS
- [moonshine on GitHub](https://github.com/moonshine-ai/moonshine): MIT-licensed core library — very low latency speech to text, intent recognition, and text to speech
